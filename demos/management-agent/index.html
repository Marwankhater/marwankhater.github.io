How the production agent works

The same conversation, with a language model and the company's ERP behind it.

One question, step by step

  1. A manager's WhatsApp message reaches the agent through a webhook. Only registered numbers get an answer.
  2. The model reads the question and picks what to look up: a branch's sales, attendance, stock or returns.
  3. Figures are read live from the ERP. The model words the answer but never invents a number.
  4. A morning summary goes out on a schedule, and an alert is sent as soon as a figure looks off.
  5. Anything that changes data, like a purchase order, is shown first and created only after a yes, as a draft for approval.

What this page shows

  • Any branch from 1 to 6, by number, with sales, margin, attendance or returns. Branch 7 gets "we only have 6".
  • The purchase order flow: low stock, a proposed order, then a draft only after you confirm.
  • The table on the right highlights exactly the rows each answer is about.

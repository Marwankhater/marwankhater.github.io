    How the production agent works

    The same conversation, with a language model and the business's ERP behind it.

    One booking, step by step

    1. The customer's WhatsApp message reaches the agent through a webhook.
    2. The model works out the day and time the customer means and asks when something is missing.
    3. Free slots are read from the ERP schedule at that moment, so the agent never offers a slot that is taken.
    4. The booking is created in the ERP only after the customer confirms, and reminders are sent from the same record.

    What this page shows

    • Thursday, Friday and Saturday, each with its own free slots. A taken time is refused with the free ones listed. The demo's today is Wednesday, so "بكرة" (tomorrow) means Thursday and "بعد بكرة" means Friday.
    • Change or cancel a booking: the same ERP row updates, and a cancelled slot becomes free again.
    • The chat and the ERP table always show the same day and time.
